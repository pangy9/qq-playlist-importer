# QQ 音乐分类歌单导入器

一个用于 QQ 音乐网页版的 Tampermonkey 脚本。读取分类 CSV，按歌曲的精确 songmid 逐首打开详情页，通过「更多 → 添加到」将歌曲加入目标歌单。

## 安装

1. 在桌面浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 选择一种界面语言：[中文版](qq-playlist-importer.user.js) / [English version](qq-playlist-importer.en.user.js)。在 Tampermonkey 管理面板新建脚本，删除默认模板，粘贴所选文件的全部内容并保存。**只安装和启用其中一版，不要同时运行两版。**
3. 打开 [QQ 音乐网页版](https://y.qq.com/)并登录，页面会显示导入面板。运行不需要 Node.js 或本地服务。

## 从收集到导入

1. 在 QQ 音乐收集待整理的歌曲。
2. 使用 [Playlist Out](https://github.com/LengxiQwQ/playlistout)（[官网](https://playlistout.lengxiqwq.com/)）导出歌曲资料，保留原始备份。
3. 用 AI 辅助分类，再人工复核类别和歌曲版本。保留原始 ID，不要让 AI 按歌名猜测或替换歌曲 ID。
4. 将资料整理为下述 CSV，选择文件并确认目标歌单后开始导入。导出文件可能需要补充分类和 songmid，不能直接把歌曲链接当作 ID。

## CSV 格式

使用 UTF-8 编码、英文逗号分隔，首行必须是表头；支持 BOM、双引号转义和常见换行。只接受 CSV，不能直接导入 JSON、Excel 或 Markdown。**两版使用相同的中文 CSV 表头，`说唱标签` 都填写「是」或「否」；界面语言不改变歌曲 ID、类别或目标歌单名称。**

| 精确列名 | 要求与用途 |
| --- | --- |
| `QQ歌曲ID` | 必需，填写精确的 QQ 音乐 **songmid** |
| `建议主类别` | 必需，按此字段分组 |
| `歌曲标题` | 可选，用于显示与日志 |
| `歌手` | 可选，用于日志 |
| `序号` | 可选，用于显示与日志 |
| `歌曲状态` | 可选，包含「下架」或「无版权」的行会跳过 |
| `说唱标签` | 可选，严格为「是」时可额外加入一个说唱歌单 |

```csv
序号,歌曲标题,歌手,建议主类别,QQ歌曲ID,歌曲状态,说唱标签
1,示例歌曲,示例歌手,放松,REPLACE_WITH_EXACT_SONGMID,正常,否
```

示例 MID 是占位符，必须替换后才能导入。songmid 通常是详情链接 `/songDetail/<songmid>` 的末段，需保留大小写和前导零；不要填写纯数字 songid、歌单 ID、歌曲链接或其他平台的 ID。标题和歌手不参与歌曲匹配。

缺少 MID 或类别的行会跳过；每行列数必须与表头一致。解析器不会严格检查所有引号错误或 MID 格式，导入前请检查重复项和歌曲版本。

## 操作

1. 选择 CSV，检查分类数量与跳过数量。
2. 填写各分类的目标歌单名，也可设置统一前缀。名称中的非法字符会被替换，不同分类可能得到相同名称，请人工检查；类别对应名称留空会跳过该类别。
3. 目标按完整名称匹配，请提前建立**名称唯一**的歌单。脚本不支持歌单链接或歌单 ID；找不到目标菜单项时会尝试新建歌单；点击创建不能证明创建或入库成功，请人工核对。
4. 如有说唱标记，可选择额外收录，并填写非空的目标名称。
5. 点击「开始导入」，保持**单标签页、同一 QQ 账号**运行，期间不要操作该标签页。
6. 可暂停后继续，或查看、导出当前报告。报告按「MID + 歌单名」计数，区分操作成功、失败、未执行和未知结果；关闭报告保留断点。

## 导出日志与失败重导

- 导出日志保留输入 CSV 的全部原始列名、列序、每行值和额外列，在末尾追加状态、失败原因、目标歌单和识别字段。双目标会为同一原始行分别导出两行；跳过行也保留。中文状态为「操作成功／失败／未执行／已处理（结果未知）／已跳过」，英文版对应 `Operation completed / Failed / Pending / Processed (result unknown) / Skipped`。
- 追加字段名采用 `__qqimp_N_status`、`__qqimp_N_reason`、`__qqimp_N_target`、`__qqimp_N_meta`。与原列重名时使用另一个编号，重新导出不会不断增加日志列。
- 可筛选「失败」行，保留**全部列和识别字段**，另存为 UTF-8 CSV，再选择该文件开始新任务；也可直接选择完整日志。日志重导只选择失败或未执行的实际目标，不重新展开主分类与说唱歌单。因此主目标操作成功、说唱目标失败时，只重导说唱目标。中英文日志可互相读取。
- 不要删除或修改追加字段、歌曲 ID 或目标列；检测到识别字段损坏会阻止重导。删除识别列可能使文件被当作普通分类 CSV，失去只重导失败目标的能力。未知结果不会自动重导，应先人工检查。两版沿用日志里的目标名称，请确认当前账号和名称；这不能替代真实入库核验。
- 继续旧任务仍不会自动重试失败项。旧断点没有保存原始 CSV 时，无法还原当时的额外列，界面会提示。

## 使用限制

- 暂停不会撤销已经开始的当前网页动作；放弃任务只清除断点，不移除已添加歌曲，也不能撤销在途操作。
- 网页改版、加载慢、登录失效或平台限制可能导致失败或误判。脚本尚未严格核验页面实际歌曲 ID，也没有读取目标歌单成员确认入库。报告中的「操作成功」不等于已核验成功，请到目标歌单核对 MID、版本和数量。
- 断点及所选 CSV 的原始资料保存在 QQ 音乐站点的 localStorage，该站点及同源脚本可能读取；不绑定账号，也没有跨标签页互斥。开始新任务会替换旧断点；继续不会自动重试失败项，连续三次异常会暂停。
- 同一任务内相同 MID 与目标名称只处理一次，不能保证重新导入没有重复或其他副作用。
- 日志保留输入资料；分享前请去除私人信息。来自不可信输入的日志可能含电子表格公式前缀，不要直接用电子表格打开。
